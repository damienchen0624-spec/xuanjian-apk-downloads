# 玄鉴 0.4.3

- 一级页面简洁，排盘、解读、原文及复盘分为二级页面。
- 铜钱投币增加动画、爻值与进度反馈；六次完成后静默保护，连续点击不会覆盖结果。
- 支持清空当前输入重新起卦，已保存档案保留。
- 卦象页直接查看卦辞、爻辞和象传，突出本卦动爻。
- 档案区分六爻案例和个人八字，按姓名、出生信息保存和查找。
- 设置集中管理账号、GPT连接和App更新，去除重复入口；顶部标明本地档案或云端档案。
- 返回键优先返回上一级工作页面；沿用包名、原签名及档案存储位置。

## 如何更新

0.4.2 中打开「连接 GPT → App 更新 → 检查 App 更新」，选择「下载并安装更新」，在 Android 系统中确认安装。升级后入口为「设置 → App 更新」。可直接覆盖安装，无需卸载；本地档案保留。

首次使用应用内安装时，Android 可能要求允许玄鉴安装更新。联网用于检查及下载，排盘和本地档案可离线使用。
